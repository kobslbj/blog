# Justin's Blog

Personal blog built with Next.js.

Based on [Vercel's Portfolio Blog Starter](https://github.com/vercel/examples/tree/main/solutions/blog).

## Tech Stack

- **Framework**: Next.js 16 + React 19
- **Styling**: Tailwind CSS v4
- **Content**: MDX
- **Font**: Geist
- **Linting**: Biome

## Getting Started

```bash
pnpm install
pnpm dev
```

## Adding Posts

Create a `.mdx` file in `app/blog/posts/`:

```mdx
---
title: 'Post Title'
publishedAt: '2024-01-01'
summary: 'Post summary'
---

Your content...
```
